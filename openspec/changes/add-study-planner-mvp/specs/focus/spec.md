## ADDED Requirements
### Requirement: Customizable Pomodoro Timer
The system SHALL provide a pomodoro timer with customizable focus and break durations.

#### Scenario: Run a custom pomodoro and log time
- **WHEN** the user starts a 50/10 pomodoro linked to a task
- **THEN** the timer runs with those durations
- **AND** upon completion, focus time is recorded on the task
