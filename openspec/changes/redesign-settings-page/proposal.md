# Change: Redesign Settings Page

## Why
The current settings page is basic and lacks visual appeal. The user requested a beautiful, functional, and "openspec" compliant redesign.

## What Changes
-   **UI Overhaul**: Complete redesign using Tailwind CSS, adopting a card-based layout with modern typography and spacing.
-   **UX Improvements**: Better feedback (toasts), smooth transitions, and clear organization of settings.
-   **Functionality**: Retain all existing features (Push, Daily Summary, Timezone).
-   **Structure**: Refactor `SettingsPage.tsx` to be more modular and maintainable.

## Impact
-   **Affected specs**: settings (new spec needed)
-   **Affected code**: `client/src/components/settings/SettingsPage.tsx`
