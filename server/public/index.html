邮箱验证提示

开发模式下，注册成功后会在服务器控制台打印：
[dev] verify-email token for you@example.com:
复制 TOKEN 到脚本或页面提示处即可验证邮箱。

环境变量

建议复制 server/.env.example 为 .env 并填写：
  • JWT_SECRET
  • SUPABASE_URL / SUPABASE_SERVICE_ROLE_KEY
  • VAPID_SUBJECT / VAPID_PUBLIC_KEY / VAPID_PRIVATE_KEY
